# Kategorie-Icons

Lege hier ein Icon pro Kategorie ab. Dateiname == `category.id` aus
`js/categories.js`. Fehlt eine Datei, wird das Emoji aus dem Katalog
gerendert — kein Fehler, kein Blocker.

Erwartete Dateinamen:

**Gut:**
- `source_ok.png`
- `factcheck.png`
- `pubmedia.png`
- `science.png`
- `ai_labeled.png`

**Schlecht:**
- `clickbait.png`
- `no_source.png`
- `conspiracy.png`
- `urgency.png`
- `ai_hidden.png`

Empfohlene Auflösung: quadratisch, ~96×96 px, transparenter Hintergrund
(PNG). Wird auf ca. 4.5 % der Bildschirmbreite skaliert.
